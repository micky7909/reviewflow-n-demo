② 연결 상태

제작 서버를 확인하고 있습니다.

Descript API 토큰이 아닙니다. 접근키는 저장하지 않고 현재 탭에서만 사용합니다.

처음 한 번: API 토큰 연결

Descript의 Settings → API tokens에서 만든 토큰을 Render의 dayen-video-api → Environment에 DESCRIPT_API_TOKEN으로 저장하세요. 이 화면이나 채팅에 토큰을 붙여 넣지 않습니다.

저장 후 배포가 끝나면 연결 상태를 다시 확인하세요. 별도 Claude API 키는 쓰지 않습니다.

Descript 공식 안내 · Render 설정

③ 현재 회차 제작

편집실에서 회차를 고르고 고해상도 닥터냥 원본을 넣어주세요.

기본 하루 2개 새 프로젝트 · 20~90초 · 중복 클릭은 같은 작업으로 처리합니다. 금액 상한을 보장하는 기능은 아닙니다.

서버가 잠들거나 재시작되면 처리가 지연될 수 있습니다. 결과가 불명확한 유료 요청은 자동 재시도하지 않습니다.

④ 비공개 결과 확인

아직 조회한 작업이 없습니다.

작업 성공과 검수 완료는 다릅니다. 검은 화면·무음·자막 잘림을 확인하고, 검수한 버전만 비공개 MP4로 출력하세요. SNS 게시 기능은 없습니다.

API 연결 전에는 실제 생성이 잠겨 있습니다. 제작을 승인한 대본과 캐릭터만 Descript로 전달됩니다. 기존 로컬 초안을 사용하려면 같은 기기·브라우저에서 여세요.
