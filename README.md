# ReviewFlow N Demo

ReviewFlow N is a public static demo for a Korean SaaS-style workflow that helps creators and small businesses draft safer Naver Blog review content and Instagram Reels planning assets.

## Live URL

After GitHub Pages is enabled, the demo will be available at:

```txt
https://micky7909.github.io/reviewflow-n-demo/
```

## What this demo includes

- Korean SaaS landing page
- Blog review draft generator
- SEO/disclosure helper
- Reels storyboard generator
- Review publishing pipeline demo
- LocalStorage-based simulated trial state
- No backend, no API key, no real payment call

## Safety note

This is not an unauthorized Naver auto-posting bot. It is a human-in-the-loop drafting, review QA, disclosure, and manual publishing support tool.

For clinic or medical review content, the demo encourages personal-experience-centered language and excludes claims that guarantee treatment outcomes.
